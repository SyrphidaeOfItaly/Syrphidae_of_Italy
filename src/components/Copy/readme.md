# CopyRefButton

`<CopyRefButton :reference="html" />`: a small pill button that copies a reference as plain text
(HTML removed, "[in X]" language notes removed, "Available at" dropped). The clipboard icon turns
into a check and the label into "Copied" ("Copiato") for about two seconds.

Used in the Nomenclature reference cards and in Nomenclature references. Not global: import it
from `@/components/Copy/CopyRefButton.vue`.
