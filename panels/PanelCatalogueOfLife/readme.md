# Catalogue of Life panel

Shows how the Catalogue of Life (COL, latest release, dataset `3LR` on ChecklistBank) treats the
name of the page: accepted or synonym, its accepted name and authorship, its classification and
source, and whether it agrees with Syrphidae of Italy. For species it also compares the synonyms:
those only in COL and those only in SoI (matched on epithet + year, so different combinations of
the same name count as the same synonym).

Add `panel:catalogue-of-life` to `config/taxa_page.yml`.
